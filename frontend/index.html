NAME

seckit — automated daily cybersecurity and data engineering tools

SYNOPSIS

seckit [--list] [--run tool] [--category cat] [options]

DESCRIPTION

seckit is a curated collection of practical security and data engineering utilities, committed daily via GitHub Actions. Each tool is a standalone Python script with no shared dependencies.

The project started as a personal discipline exercise: one tool per day, every day. See docs/CATALOG.md for the full inventory.

TOOLS

CYBERSECURITY

cve-tracker(1)
Pulls the latest CVE feed from NIST NVD and filters by CVSS threshold.
Usage: ./cve-tracker --min-cvss 7.0 --days 7
port-scan(1)
Multi-threaded TCP connect scanner with banner grabbing. Not stealthy — use nmap in the real world.
hibp-check(1)
Queries Have I Been Pwned via k-anonymity — only the first 5 hex chars of sha-1 leave the client.
hash-gen(1)
Command-line hash generator. Supports md5, sha1, sha256, sha512, and PBKDF2 with configurable iterations.
password-audit(1)
Reads a password file (one per line) and reports entropy distribution, duplicates, and common-pattern matches.

DATA ENGINEERING

csv-profile(1)
Streams a CSV and reports: row count, column dtypes, null ratios, unique counts, and a top-10 value histogram.
json-validate(1)
Validates JSON against an optional JSON Schema. Pretty-prints on success; shows exact line/column on failure.
sql-generate(1)
Reads a CSV header and emits CREATE TABLE + INSERT INTO statements. Infers SQL types from sample data.
regex-test(1)
Interactive regex tester. Supports PCRE-style flags and capture group extraction.

EXAMPLES

Run the CVE tracker and only show high-severity: $ ./cve-tracker --min-cvss 7.5 --days 7 Check if a password has been in a breach: $ ./hibp-check 'correct horse battery staple' ✓ Not found in HIBP
